| Fichier | Étape |
|---|---|
| `support_etage_1.html` | Partage et premières fractions. |
| `support_etage_2.html` | Lire et représenter une fraction. |
| `support_etage_3.html` | Droite graduée. |
| `support_etage_4.html` | Fractions équivalentes. |
| `support_etage_5.html` | Comparer les fractions. |
| `support_etage_6.html` | Fractions décimales. |
| `support_etage_7.html` | Addition et soustraction. |
| `support_etage_8.html` | Dénominateurs différents. |
| `support_etage_9.html` | Multiplication et division. |
| `support_etage_complet.html` | Ancien support complet. |

Le lecteur utilisé actuellement est défini dans `src/lib/games/fractionstower2/components/course/CourseViewer.svelte` et ouvre `static/cours/maths/fractions/complet.html`. Ces fichiers autonomes ne sont donc pas chargés par ce lecteur.
