Étage 7

Addition et soustraction : même dénominateur

Rappel

Si les dénominateurs sont identiques, on additionne ou soustrait les numérateurs et on garde le dénominateur. Le résultat peut ensuite être simplifié.

Если знаменатели одинаковы, складывают или вычитают числители, а знаменатель оставляют прежним. Затем результат можно сократить.

Exemple

2/7 + 3/7 = 5/7.    6/8 − 2/8 = 4/8 = 1/2.

2/7 + 3/7 = 5/7. 6/8 − 2/8 = 4/8 = 1/2.

Additionner : les parts gardent la même taille

  2. Je réunis les 2 parts et les 3 parts.
  3. Je compte 2 + 3 = 5 parts colorées.
  4. Le dénominateur reste 7 : le résultat est 5/7.
