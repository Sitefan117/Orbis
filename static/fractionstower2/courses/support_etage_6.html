Étage 6

Fractions décimales et nombres décimaux

Rappel

Une fraction décimale a pour dénominateur 10, 100, 1'000, etc. Ainsi, 7/10 = 0,7 ; 23/100 = 0,23 ; 8/1'000 = 0,008. En français suisse, on écrit les milliers avec une apostrophe.

Десятичная дробь имеет знаменатель 10, 100, 1'000 и т. д. Например, 7/10 = 0,7; 23/100 = 0,23; 8/1'000 = 0,008.

Exemple

34/100 = 0,34 : le chiffre 3 représente 3 dixièmes et le chiffre 4 représente 4 centièmes.

34/100 = 0,34: цифра 3 показывает три десятых, а цифра 4 — четыре сотых.

Des centièmes à l'écriture décimale

  1. La grille contient 100 petites cases égales.
  2. 34 cases représentent 34/100.
  3. 3 dixièmes occupent 30 cases ; 4 centièmes en occupent 4.
  4. J'écris 34/100 = 0,34.

B — Je convertis dans les deux sens

Le dénominateur 10 correspond aux dixièmes, 100 aux centièmes, 1'000 aux millièmes.

1. Convertis 810 en nombre décimal.
2. Convertis 27100 en nombre décimal.
3. Convertis 41000 en nombre décimal.
4. Écris 0,35 comme fraction décimale.
5. Range dans l’ordre croissant : 0,7 ; 0,07 ; 0,77.
6. Compare 35100 et 0,4.
Correction — B — Je convertis dans les deux sens :
  1. 0,8.
  2. 0,27.
  3. 0,004.
  4. 35100.
  5. 0,07 < 0,7 < 0,77.
  6. 35100 = 0,35, donc 0,35 < 0,4.

C — Les fractions décimales dans la vie courante

Relier les fractions décimales aux francs, aux longueurs et aux contenances.

1. Réponds : 75 centimes représentent quelle fraction de 1 CHF ? Écris aussi le nombre décimal.
2. Réponds : Tu verses 3 décilitres dans une bouteille d’un litre. Quelle fraction de litre as-tu versée ?
3. Réponds : 25 cm représentent quelle fraction d’un mètre ? Écris aussi le décimal.
4. Réponds : Une bouteille contient 610 litre. Écris la quantité en nombre décimal.
5. Réponds : Une recette demande 0,25 kg de farine. Écris cette quantité en centièmes de kilogramme.
6. Réponds : Quel sac est le plus lourd : 0,4 kg ou 0,35 kg ?
Correction — C — Les fractions décimales dans la vie courante :
  1. 75100 CHF = 0,75 CHF.
  2. 310 L = 0,3 L.
  3. 25100 m = 0,25 m.
  4. 0,6 L.
  5. 25100 kg.
  6. 0,4 kg, car 0,40 kg > 0,35 kg.
