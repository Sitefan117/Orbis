# Cahiers Mesurovia

**Rôle du dossier :** cinq cahiers élèves alignés sur les cinq villages et les vingt maisons de Mesurovia.

## Cahiers élèves

| Fichier | Parcours |
|---|---|
| `fondations.html` | Grandeurs, unités, repères, longueurs et mesure réelle. |
| `conversions.html` | Tableaux des longueurs, capacités et masses ; durées non décimales. |
| `aires-perimetres.html` | Périmètres, surfaces, quadrillages, carrés et rectangles. |
| `volumes-capacites.html` | Solides, unités cubiques, pavés et liens avec les litres. |
| `missions-maitrise.html` | Réinvestissement : masses, terrains, calendrier et enquêtes. |

Les cinq chemins sont déclarés dans `src/lib/orbis/catalog/course-paths.ts`. Les cours guidés interactifs sont maintenus séparément, maison par maison, dans `src/lib/games/mesurovia/courses/`.
