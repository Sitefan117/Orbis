# Cours de mathématiques

**Rôle du dossier :** réunit les cours HTML classés par thème. Les chemins qui doivent apparaître dans l’interface sont déclarés dans [`course-paths.ts`](../../../src/lib/orbis/catalog/course-paths.ts), puis les titres et descriptions dans `src/lib/orbis/catalog/courses.ts`.

## Thèmes

| Dossier | Rôle |
|---|---|
| [`fractions/`](./fractions/README.md) | Cours complet et parcours fractionné en neuf étapes. |
| [`geometrie/`](./geometrie/README.md) | Carnet de géométrie et module de croquis. |
| [`mesures/`](./mesures/README.md) | Référence des unités et cahiers Mesurovia. |
