# Fractions

**Rôle du dossier :** cours HTML complet et supports répartis en neuf étapes progressives.

## Fichiers

| Fichier | Rôle et liens |
|---|---|
| `complet.html` | Cahier complet interactif. Le jeu Fraction Tower le charge dans son lecteur de cours via `coursePaths.fractions.complete` et `CourseViewer.svelte`. |
| `etapes.html` | Page de choix des étapes ; ses liens relatifs ouvrent les fichiers `etape-1.html` à `etape-9.html` ou le cours complet. |
| `etape-1.html` | Partage équitable et vocabulaire des fractions. |
| `etape-2.html` | Lire et représenter les fractions. |
| `etape-3.html` | Placer les fractions sur une droite graduée. |
| `etape-4.html` | Fractions équivalentes et simplification. |
| `etape-5.html` | Comparer et ordonner les fractions. |
| `etape-6.html` | Fractions décimales et nombres décimaux. |
| `etape-7.html` | Addition et soustraction avec le même dénominateur. |
| `etape-8.html` | Calculer avec des dénominateurs différents. |
| `etape-9.html` | Multiplication et division de fractions. |

Les pages sont des documents autonomes. Le catalogue Orbis publie le cours complet et la page par étapes ; les supports par étape sont ouverts depuis `etapes.html`.
