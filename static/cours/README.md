# Cours publiés

**Rôle du dossier :** cahiers HTML consultables directement dans le navigateur. Les fichiers sous `maths/` sont les chemins organisés utilisés par le catalogue Orbis.

## Sous-dossier

| Dossier | Rôle |
|---|---|
| [`maths/`](./maths/README.md) | Catalogue organisé par matière et thème. |

## Fichiers conservés à l’ancien emplacement

Ces cahiers et corrigés ont des noms historiques. Les chemins actuels du catalogue sont regroupés dans [`course-paths.ts`](../../src/lib/orbis/catalog/course-paths.ts) et pointent vers `maths/`.

| Fichier | Contenu |
|---|---|
| `cahier-sentiers-moulin.html` | Cahier élève Mesurovia : Sentiers du Moulin. |
| `cahier-clairieres-compas.html` | Cahier élève Mesurovia : Clairières du Compas. |
| `cahier-canaux-artisans.html` | Cahier élève Mesurovia : Canaux des Artisans. |
| `cahier-hautes-terres.html` | Cahier élève Mesurovia : Hautes-Terres de la Mesure. |
| `corrige-sentiers-moulin.html` | Corrigé enseignant des Sentiers du Moulin. |
| `corrige-clairieres-compas.html` | Corrigé enseignant des Clairières du Compas. |
| `corrige-canaux-artisans.html` | Corrigé enseignant des Canaux des Artisans. |
| `corrige-hautes-terres.html` | Corrigé enseignant des Hautes-Terres de la Mesure. |
| `cours-conversions-reference.html` | Ancienne version du cahier de référence sur les conversions. |

Les nouveaux cahiers sont des documents HTML autonomes : leur style et leurs interactions sont inclus dans chaque fichier. Les corrigés restent séparés des cahiers élèves.
