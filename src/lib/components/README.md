# Composants de saisie partagés

- `NumericKeypad.svelte` : pavé numérique utilisé par les jeux à réponse chiffrée.
- `touch-input.ts` : indique si un appareil tactile doit utiliser ce pavé sans ouvrir le clavier virtuel du système.

Les champs conservent la saisie classique sur ordinateur ; sur tablette tactile, le pavé reste visible dans la page.
