# fractionstower2

**Rôle du dossier :** Moteur, sauvegardes, contenus et composants de Fraction Tower.

Les neuf étages sont actifs. L’étage 9 clôt le parcours avec la multiplication et la division des fractions. La génération des questions et les contrôles de qualité sont décrits dans [l’audit pédagogique](../../../../docs/fractionstower-question-audit.md).
