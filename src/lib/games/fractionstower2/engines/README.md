# engines

**Rôle du dossier :** Calculs et génération d’exercices.

## Fichiers

- **[`ExerciseGenerator.ts](./ExerciseGenerator.ts)** — Crée les exercices des neuf étages, varie les valeurs et répartit les types de questions. Les étages 1 et 2 incluent une sélection multiple de représentations fractionnaires ; les conversions couvrent les dixièmes, centièmes et millièmes. Les comparaisons sont mélangées entre « < », « > » et « = » ; les prompts dupliqués d’une session sont écartés.  
  Dépend de : aucun import direct détecté.
